# 🌿 Kimono Bot
> Um bot místico para o Discord com estética **Jumino Core** (Stardew Valley), alimentado por Inteligência Artificial, moderação avançada, economia e painéis interativos.

## ✨ Recursos
- 🛡️ **Moderação Avançada:** Comandos como `/ban_lote`, `/mute`, `/warn` e anti-spam.
- 🎟️ **Sistema de Tickets:** Cabanas de atendimento interativas com botões.
- 🤖 **IA Integrada:** Sabedoria dos Juminos respondendo dúvidas via Google Gemini.
- 💎 **Economia & Níveis:** Cargos exclusivos e recompensas baseadas em atividade.
- 🎨 **Embeds V2:** Layouts modernos, limpos e estilizados.
